# 💀 Bro This Exists

> **"Paste your startup idea. Find out if you’re a genius… or late to the party."**

A viral, quirky, slightly savage Streamlit app that checks if your startup idea is already overdone, roasted, or actually worth building.

## 🔥 Features

- 💀 **Similar Products Radar**: Instant list of 3-5 existing startups/competitors.
- 🔥 **Originality Score Bar**: Visual 1-10 progress rating of your concept's uniqueness.
- ⚠️ **Market Saturation Level**: Low / Medium / High market saturation breakdown.
- 😈 **Short Punchy Roast**: Funny, sarcastic, slightly savage explanation (choose Normal 😇 or Savage 😈 mode).
- 💡 **Better / Niche Pivot**: Smart, actionable alternative angle to save your idea.
- 🚀 **Final Verdict**: `BUILD IT NOW`, `MAYBE / PIVOT`, or `DO NOT BUILD`.
- 💬 **VC Real Talk**: Random hilarious quotes ("Even your senior tried this in 3rd year and gave up").
- 📋 **Copy & Share**: 1-click clipboard export and Twitter / X sharing button!
- ⚡ **Offline Roast Engine**: Works out of the box with or without an API key!

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Dhanya562004/Bro-This-Exists.git
cd Bro-This-Exists
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Set up Environment Variables (Optional)
Create a `.env` file in the root directory:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
*(Note: If no API key is set, the app will run seamlessly using its built-in smart roast engine!)*

### 4. Run the app locally
```bash
streamlit run app.py
```
